# Scam-Check
A AI agent build for older adults that you facetime to check if an email, video, photo, or link is a scam.
Scam Check works by having the person call the number (+1 628-233-5326) on Facetime and a agent powered by Chert will pick up. The agent will then take a photo of the screen and and determine if it's a scam with ChatGPT. If it's a scam, the screen will turn red and Scam Check will say scam, don't reply or send money.
